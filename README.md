# 트래블 버디 (Travel Buddy)

여행 전 준비물 챙기기부터 일정 관리, 가계부, 바우처 보관까지 한 곳에서 해결하는 올인원 여행 플랫폼 프론트엔드 프로토타입입니다.

> 기록의 번거로움은 줄이고, 여행의 순간에 집중하게 한다.

## 주요 기능
- **로그인 / 회원가입 / 데모 계정** — 계정별 데이터 분리 (localStorage 기반 데모 인증)
- **스마트 타임라인** — 카테고리 자동 분류, 일정·지도 스플릿 뷰, 도보/대중교통/차량 소요시간 계산, 여유 일정 모드(휴식 자동 추천), 동선 최적화
- **실시간 여행 가계부** — 실시간 환율 변환, 카테고리별 지출 차트, 예산 대비 현황, 영수증 스캔(데모)
- **스마트 체크리스트** — 여행지·계절·동행인 맞춤 준비물 자동 생성, D-Day 할 일, 공동 준비물 담당자 지정
- **보관함** — 바우처 업로드 및 일정 연결, 오프라인 열람
- **협업** — 일행 초대, 그룹 채팅, 편집 기록

## 기술
Vanilla HTML / CSS / JavaScript 단일 파일, 빌드 없음. 반응형(모바일 탭바·스와이프 삭제), 라이트/다크 테마.

## 실행
`index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속하세요. 로그인 화면의 **데모 여행으로 둘러보기**로 샘플 데이터를 바로 확인할 수 있습니다.

## 향후 과제
Google Maps API 연동, 실제 OCR(Vision/CLOVA), 백엔드 동기화(Firebase/Supabase), React 컴포넌트화
